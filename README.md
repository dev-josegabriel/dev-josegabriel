## Projetos em destaque

### MetaRun API (em produção)

API REST de uma plataforma de consultoria de corrida com treino adaptativo gerado por IA e assinatura paga.

- Autenticação com JWT, senhas com BCrypt e login com Google
- Integração com a API do Google Gemini (chat e geração de treinos)
- Pagamentos com Mercado Pago (cartão e Pix), com webhook de confirmação
- Controle de acesso por assinatura, e-mails transacionais e deploy com Docker

**Tecnologias:** Java 17 · Spring Boot · Spring Security · JPA · PostgreSQL · Docker
*Repositório privado, por ser um projeto de cliente.*

### Calçados BG API

Back-end de uma loja de calçados, com pedidos, autenticação e pagamentos via Pix.

**Tecnologias:** Java · Spring Boot · PostgreSQL
*Repositório privado, por ser um projeto de cliente.*

### Biblioteca API

API REST para gestão de biblioteca, com usuários, livros e empréstimos.

**Tecnologias:** Java · Spring Boot · PostgreSQL · JPA
[Ver código](https://github.com/dev-josegabriel/Projetos/tree/main/Java/bibliotecaAPI)
